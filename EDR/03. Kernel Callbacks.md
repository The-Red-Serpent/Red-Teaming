## Kernel Notification Callback
The kernel's callback mechanism provides a general way for drivers to request and provide notification when certain conditions are satisfied.

A driver can create a callback object, and other drivers can request notification for conditions associated with this driver-defined callback. In addition, the system defines three callback objects for driver use.

A Windows kernel notification callback is a mechanism provided by the Windows kernel through specific kernel APIs/DDIs that allows a kernel-mode driver to register its own callback function for a particular type of system event. Windows exposes different registration APIs for different event types, such as process creation, thread creation, DLL/EXE image loading, registry operations, and certain process/thread object operations. Once a driver registers its callback, the Windows kernel maintains that registration and invokes the driver's callback when the corresponding event occurs, passing event-related information to the driver.

EDRs use Windows kernel notification callbacks as a telemetry mechanism, the EDR’s kernel-mode driver registers callback functions through Windows-provided kernel API When a relevant event occurs, Windows invokes the registered callback and passes event-related data to the EDR driver, such as information about the event, process, thread, image, or operation, depending on the callback mechanism. The EDR driver can then collect and send this telemetry to the EDR’s user-mode components or other security-processing components, where it is correlated and analyzed with other telemetry to determine whether the activity is suspicious or malicious and, depending on the product, may generate an alert or take a protective action.
<br></br>

| Windows API / DDI                    | Registers for              | Callback is invoked when…                      | Typical security use                   |
| ------------------------------------ | -------------------------- | ---------------------------------------------- | -------------------------------------- |
| `PsSetCreateProcessNotifyRoutineEx`  | Process notifications      | A process is created or exits                  | Process monitoring                     |
| `PsSetCreateThreadNotifyRoutine`     | Thread notifications       | A thread is created or deleted                 | Thread monitoring                      |
| `PsSetLoadImageNotifyRoutine`        | Image-load notifications   | An EXE/DLL image is loaded into a process      | DLL/injection monitoring               |
| `ObRegisterCallbacks`                | Object-operation callbacks | Certain process/thread handle operations occur | Process protection / handle monitoring |
| `CmRegisterCallbackEx`               | Registry notifications     | Registry operations occur                      | Registry monitoring                    |
| File-system **minifilter** callbacks | File-system operations     | File I/O operations occur                      | File monitoring / ransomware detection |
