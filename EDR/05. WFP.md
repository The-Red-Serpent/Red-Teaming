## Windows Filtering Platform
Windows Filtering Platform (WFP) is a Windows networking framework that provides a set of APIs and filtering mechanisms that allow software to monitor, inspect, and control network traffic. It provides different points in the Windows networking stack where applications or security software, such as an EDR or firewall, can observe network activity and decide whether to allow or block it.

WFP can be used from user mode through its APIs, while more advanced filtering can be implemented using a kernel-mode WFP callout driver.


An EDR typically installs a kernel-mode driver that integrates with the Windows Filtering Platform (WFP). This driver registers one or more WFP callouts and creates filters that specify which network activity the EDR is interested in. When network activity reaches the relevant WFP layer and matches one of the EDR's filters, WFP invokes the corresponding callout implemented by the EDR's kernel driver. The callout can then inspect the available network and process information and participate in the decision to allow, block, or defer the connection. The driver can also send the collected network telemetry to the EDR's user-mode service, where it can be correlated with other events and analyzed for malicious behavior.
