## Windows Filtering Platform
Windows Filtering Platform (WFP) is a Windows networking framework that provides a set of APIs and filtering mechanisms that allow software to monitor, inspect, and control network traffic. It provides different points in the Windows networking stack where applications or security software, such as an EDR or firewall, can observe network activity and decide whether to allow or block it.

WFP can be used from user mode through its APIs, while more advanced filtering can be implemented using a kernel-mode WFP callout driver.
