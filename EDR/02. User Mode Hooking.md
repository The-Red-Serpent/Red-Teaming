## User Mode Hooking
User-mode hooking is a technique where an AV/EDR modifies functions loaded in a process’s user-mode memory to redirect execution to its own code, allowing it to inspect, monitor, or block operations before the original function executes.

## API Hooking
API hooking is a technique used to intercept API calls made by a program or
process. This interception allows EDRs to monitor and/or control the behavior of
applications. Attackers also frequently abuse hooking techniques for malicious
purposes, such as keylogging
