## Compiler
When you write a program in C, you are writing instructions in a language that is easier for humans to understand, but the CPU cannot directly understand C. The compiler takes your C code, such as `hello.c`, and translates it into assembly language, producing something like `hello.s`. Assembly is a human-readable representation of the instructions that a particular CPU understands. For example, if you write `x = a + b` in C, the compiler might translate it into assembly such as `add eax, ebx`. The assembler then takes the assembly code in `hello.s` and converts it into actual machine-code bytes that the CPU can execute, producing `hello.o`, which is called an object file. This object file may still depend on code from libraries; for example, if your program uses `printf()`, that functionality comes from a library. The linker takes `hello.o` and connects it with the required libraries and other object files, resolving things like where `printf()` comes from, and then produces the final executable, such as `hello`. The operating system can then load this executable into memory and the CPU executes the machine code. 

Different CPUs have different instruction sets, which is why architectures such as x86, x86-64, ARM, etc. have different assembly languages. When reverse-engineering a compiled program, you often don't have the original C code, so tools like Ghidra look at the machine code, disassemble it into assembly, and then try to reconstruct C-like pseudocode. Ghidra cannot recover the exact original C code; it is making an educated guess about what the compiled program is doing.

```
┌──────────────┐
│   hello.c    │  ← You write C
└──────┬───────┘
       ↓
┌──────────────┐
│   Compiler   │  ← Converts C → Assembly
└──────┬───────┘
       ↓
┌──────────────┐
│   hello.s    │  ← Assembly
└──────┬───────┘
       ↓
┌──────────────┐
│   Assembler  │  ← Assembly → Machine code
└──────┬───────┘
       ↓
┌──────────────┐
│   hello.o    │  ← Object file
└──────┬───────┘
       ↓
┌──────────────┐
│    Linker    │  ← Connects code + libraries
└──────┬───────┘
       ↓
┌──────────────┐
│    hello     │  ← Final executable
└──────┬───────┘
       ↓
      CPU
```
