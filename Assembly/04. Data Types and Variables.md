## Data Types
In x64 assembly, the hardware recognizes only raw binary sequences of specific bit-lengths rather than strongly-typed abstractions. There is no native type safety; the CPU interprets a sequence of bits as signed, unsigned, or floating-point based entirely on the specific instruction you choose to execute. [1]  


## Integer Data Types 

| Data Type | Size (Bits) | Size (Bytes) | Range (Unsigned) | Range (Signed / Two's Complement)  |
| --- | --- | --- | --- | --- |
| BYTE | 8 | 1 | 0 to 255 | -128 to 127  |
| WORD | 16 | 2 | 0 to 65,535 | -32,768 to 32,767  |
| DWORD (Doubleword) | 32 | 4 | 0 to 4,294,967,295 | -2,147,483,648 to 2,147,483,647  |
| QWORD (Quadword) | 64 | 8 | 0 to 2⁶⁴-1 | -2⁶³ to 2⁶³-1  |



## Floating-Point Data Types 

| Assembly data type |               Size | C/C++ equivalent | Description                                                   | Common directive |
| ------------------ | -----------------: | ---------------- | ------------------------------------------------------------- | ---------------- |
| REAL4              |  32 bits (4 bytes) | `float`          | Single-precision floating-point                               | `dd` / `REAL4`   |
| REAL8              |  64 bits (8 bytes) | `double`         | Double-precision floating-point                               | `dq` / `REAL8`   |
| REAL10             | 80 bits (10 bytes) | `long double`*   | Extended-precision floating-point; mainly associated with x87 | `dt` / `REAL10`  |


## Vector / SIMD Data Types 
Modern x64 development heavily relies on Single Instruction Multiple Data (SIMD) extensions for parallel processing. These act as containers for packed chunks of smaller integers or floats. 

| Assembly data type |                Size | Used with               | Description  |
| ------------------ | ------------------: | ----------------------- | ------------ |
| XMMWORD            | 128 bits (16 bytes) | SSE / XMM registers     | 128-bit data |
| YMMWORD            | 256 bits (32 bytes) | AVX / YMM registers     | 256-bit data |
| ZMMWORD            | 512 bits (64 bytes) | AVX-512 / ZMM registers | 512-bit data |

## Variables
A Variable is defined by  by reserving memory and optionally putting an initial value into it. When declaring initialized variables in your data segment, you use pseudo-instructions (directives) that tell the assembler how much space to allocate. Directives define how much space to allocate in memory

- Syntax
```
variable_name  directive  value
```

## Directives
If you're using **NASM x64 assembly**, here are the main data-definition directives you'll encounter:

| Directive | Meaning           |     Size | Example          |
| --------- | ----------------- | -------: | ---------------- |
| `DB`      | Define Byte       |   1 byte | `x db 10`        |
| `DW`      | Define Word       |  2 bytes | `x dw 1000`      |
| `DD`      | Define Doubleword |  4 bytes | `x dd 100000`    |
| `DQ`      | Define Quadword   |  8 bytes | `x dq 123456789` |
| `DT`      | Define Ten Bytes  | 10 bytes | `x dt 0`         |
| `DO`      | Define Octaword   | 16 bytes | `x do 0`         |
| `DY`      | Define YMMWORD    | 32 bytes | `x dy 0`         |
| `DZ`      | Define ZMMWORD    | 64 bytes | `x dz 0`         |

### Reserve-space directives

These are used when you want to **reserve memory without initializing it**:

| Directive | Meaning            | Size per element | Example          |
| --------- | ------------------ | ---------------: | ---------------- |
| `RESB`    | Reserve Byte       |           1 byte | `buffer resb 64` |
| `RESW`    | Reserve Word       |          2 bytes | `buffer resw 10` |
| `RESD`    | Reserve Doubleword |          4 bytes | `buffer resd 10` |
| `RESQ`    | Reserve Quadword   |          8 bytes | `buffer resq 10` |
| `REST`    | Reserve Ten Bytes  |         10 bytes | `buffer rest 2`  |
| `RESO`    | Reserve Octaword   |         16 bytes | `buffer reso 2`  |
| `RESY`    | Reserve YMMWORD    |         32 bytes | `buffer resy 2`  |
| `RESZ`    | Reserve ZMMWORD    |         64 bytes | `buffer resz 2`  |



## Constants
There are several directives provided by assembly that define constants
| Directive | Purpose                      | Redefinable? | Example            |
| --------- | ---------------------------- | ------------ | ------------------ |
| `EQU`     | Defines a constant           | No           | `SIZE equ 100`     |
| `%assign` | Defines a numeric constant   | Yes          | `%assign SIZE 100` |
| `%define` | Defines a text/numeric constant | Yes        | `%define SIZE 100` |
