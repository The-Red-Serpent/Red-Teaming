## Heap
The heap is a region of a process's virtual address space used for dynamic memory allocation. It is managed by a memory allocator, which provides and releases chunks of memory as the program requests them. The heap is not a single fixed-size block of memory; it can grow, shrink, and contain allocated and free regions of different sizes.

The heap lets us create memory dynamically when we don't know beforehand how much memory we need or how long we need it to live.

Heap memory is not automatically cleaned up when you are finished using it. In C, memory allocated with malloc() must be explicitly released using free(). If you don't release it, the memory can remain allocated and cause a memory leak.
