## LAPS
Microsoft Windows LAPS (Local Administrator Password Solution) is a Windows security feature that automatically manages the password of a designated local administrator account on Windows devices. It generates a unique, randomly generated, complex password for each device, sets that password on the local administrator account, and backs up the password to Active Directory Domain Services (AD DS) or Microsoft Entra ID, depending on the deployment.

LAPS also automatically rotates the password according to a configured password-expiration policy and restricts password retrieval to authorized administrators.

LAPS is implemented because organizations often have local administrator accounts on many Windows computers, and if the same password is used on multiple machines, an attacker who compromises one computer can obtain the local administrator's password hash and use techniques such as Pass-the-Hash to authenticate to other computers without knowing the actual plaintext password. LAPS addresses this by giving each Windows endpoint a unique, randomly generated local administrator password and automatically rotating that password.

## LAPS Storage
In Active Directory, the LAPS password is saved directly inside the specific computer object's properties as an attribute . It is stored as text on that individual device entry and is hidden from regular users using access rules

## Legacy Microsoft LAPS attributes
In the domain’s computer objects, the implementation of legacy Microsoft LAPS results in the addition of two attributes:[1]

- ms-Mcs-AdmPwd: plain-text administrator password
- ms-Mcs-AdmPwdExpirationTime: password expiration time

## Modern Windows LAPS attributes
Native Windows LAPS adds several new attributes to computer objects:[2]

- msLAPS-Password: clear-text password blob stored as JSON when encryption is not enabled
- msLAPS-PasswordExpirationTime: scheduled expiration time
- msLAPS-EncryptedPassword: encrypted current password
- msLAPS-EncryptedPasswordHistory: encrypted password history
- msLAPS-EncryptedDSRMPassword / msLAPS-EncryptedDSRMPasswordHistory: encrypted DSRM password data for domain controllers
- msLAPS-CurrentPasswordVersion: GUID-based version tracking used by newer rollback-detection logic (Windows Server 2025 forest schema)

The LAPS computer objects and their attributes can be enumerated according to normal Active Directory directory permissions, but these attribute are confidential attribute, so its password value cannot normally be read by ordinary users. Only accounts that have the required permissions to read the confidential attribute can retrieve the LAPS password. . By default, no standard user or group can read them; access must be explicitly delegated via Access Control Lists (ACLs) to specific authorized administrators or helpdesk groups.

- Enumerating if LAPS is installed on the machine
```
# Check if the DLL is installed locally
Get-ChildItem 'c:\program files\LAPS\CSE\Admpwd.dll'
dir "C:\Program Files\LAPS\CSE"

# Checking registry
reg query "HKLM\Software\Policies\Microsoft Services\AdmPwd" /v AdmPwdEnabled
```
