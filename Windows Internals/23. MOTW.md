## MOTW
Mark of the Web (MotW) is Windows security metadata that identifies a file as originating from an untrusted or potentially unsafe security zone, such as the Internet. It  tags files downloaded from the internet with a special metadata stream. It doesn’t change the file’s content, but it adds an alternate data stream (ADS) called `Zone.Identifier`. Windows and applications use this origin information to decide whether additional security controls, warnings, or restrictions should be applied to the file.

This hidden tag tells Windows (and apps like Office, PowerShell, or SmartScreen):  “This file came from the web. Treat it with caution.”

- Enumeration
```
Get-Item .\invoice.docx -Stream Zone.Identifier
```

- Removing MOTW
```
Unblock-File -Path "C:\path\to\your\file.exe"
```

```
.ade, .adp, .app, .asp, .bas, .bat, .cer, .chm, .cmd, .com, .cpl, .crt, .csh, .der, .dll,
.exe, .fxp, .gadget, .hlp, .hta, .htm, .html, .img, .inf, .ins, .iso, .isp, .its,

.mst, .msu, .ops, .pcd, .pl, .plg, .prg, .ps1, .ps1xml, .ps2, .psc1, .psc2, .psd1,
```
