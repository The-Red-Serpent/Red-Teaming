## For Loop
- Syntax
```
for (initialization; condition; update) {
    // code
}
```
- Example
```
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
```

## While loop
- Syntax
```
while (condition) {
    // code
}
```

- Example
```
int i = 0;

while (i < 5) {
    printf("%d\n", i);
    i++;
}
```


## Do While Loop

- Syntax
```
do {
    // code
} while (condition);
```

- Example
```
int i = 0;

do {
    printf("%d\n", i);
    i++;
} while (i < 5);
```
