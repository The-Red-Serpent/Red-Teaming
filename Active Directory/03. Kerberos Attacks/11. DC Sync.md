## DC Sync

A DCSync attack is a credential theft technique in which an attacker impersonates a legitimate Active Directory domain controller and requests password data through the directory replication process. Instead of dumping password hashes directly from a domain controller's memory, the attacker abuses the replication protocol to ask the real domain controller to send account credentials.
In a normal environment, domain controllers regularly replicate user and computer account information with each other. If an attacker obtains an account with the necessary replication permissions (or compromises an administrator account), they can use tools such as Mimikatz to:

- Pretend to be another domain controller.
- Request replication of directory data.
- Receive password hashes for selected or all domain users, including highly privileged accounts like the krbtgt account.

Those password hashes can then be:
- Cracked offline to recover plaintext passwords.
- Used in Pass-the-Hash attacks.
- Used to forge Golden Ticket attacks if the krbtgt hash is stolen.

## Required permissions

An attacker typically needs an account with one of these rights:

- Replicating Directory Changes
- Replicating Directory Changes All
- Replicating Directory Changes In Filtered Set

These permissions are often granted to:
- Domain Controllers
- Domain Admins
- Enterprise Admins
- Certain synchronization services (if configured)
