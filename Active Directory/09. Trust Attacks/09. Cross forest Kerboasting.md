## Cross forest Kerboasting

Kerberoasting is an Active Directory attack where an authenticated user requests Kerberos TGS (Ticket Granting Service) tickets for accounts that have SPNs (Service Principal Names).

The important point is that the returned TGS can contain material derived from the service account's password. An attacker can take the ticket offline and attempt to recover the service account password without repeatedly interacting with the domain.


If two AD forests/domains have an appropriate bidirectional trust, a user in Forest/Domain A may be able to request service tickets for suitable accounts in Forest/Domain B.

## Attack Flow

```

The scenario in the material can be summarized as:

1. Obtain low-privileged access to Forest A
             ↓
2. Discover a trust with Forest B
             ↓
3. Identify SPNs/service accounts in Forest B
             ↓
4. Request TGS tickets for suitable services
             ↓
5. Extract the Kerberos ticket/hash material
             ↓
6. Perform offline password guessing
             ↓
7. Recover a weak service-account password
             ↓
8. Use the recovered credentials to gain additional access
```


The significant advantage is that password cracking happens offline.
